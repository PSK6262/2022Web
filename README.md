# 게이머 파티 (GamerParty)

게이머 파티는 온라인 게임을 함께 플레이할 파티원이나 듀오를 찾고, 자유롭게 이야기를 나눌 수 있는 게임 커뮤니티 웹사이트입니다.

- 개발자: 안동대학교 박성국 (이메일: qkrxotn60@naver.com)
- 개발 환경: Java 11, JSP/Servlet, Apache Tomcat 9.0, Oracle Database 19c

---

## 1. 웹사이트 기능 안내

1. 회원 관리
- 회원가입 및 로그인: 이메일 아이디와 비밀번호, 닉네임을 입력하여 가입하고 로그인합니다.
- 내 프로필 관리: 내가 주로 하는 게임과 포지션을 설정할 수 있고, 프로필 사진을 등록하거나 변경할 수 있습니다.
- 비밀번호 찾기: 가입한 이메일 주소를 입력하면 해당 메일함으로 비밀번호를 발송해 줍니다.

2. 게시판 (파티원 모집 및 자유 게시판)
- 파티 모집 글 작성: 함께 게임할 시간대나 마이크 사용 여부를 적어 파티원을 모집할 수 있습니다.
- 자유 토크: 게임 팁이나 일상 이야기를 자유롭게 올릴 수 있습니다.
- 게시글 보기 및 페이징: 등록된 글 목록을 페이지 번호로 나누어 볼 수 있으며, 상세 내용을 확인할 수 있습니다.

3. 관리자 제어 콘솔
- 관리자 로그인: 관리자 계정으로 접속하여 게시판과 유저를 관리합니다.
- 관리 작업: 규칙을 어긴 불량 게시글을 강제로 삭제하거나, 문제 유저를 정지(밴)시키거나 해제할 수 있습니다.

## 2. 2022년 원본 버전과 현재 업데이트 비교

2022년에 처음 제작된 프로젝트를 바탕으로, 실행 안정성을 높이고 겉모습을 요즘 웹사이트처럼 편리하게 고쳤습니다.

| 구분 | 2022년 초기 버전 | 현재 업데이트 내용 |
| :--- | :--- | :--- |
| 폴더 구조 | 웹 루트 폴더에 화면 파일(JSP)과 사진 파일이 모두 뒤섞여 있었습니다. | 화면 파일은 views 폴더에, 사진 파일은 assets/images 폴더에, 데이터베이스 파일은 resources/sql 폴더에 종류별로 나누어 깔끔하게 정리했습니다. |
| 데이터베이스 | 개인 PC용 임시 데이터베이스(H2)를 사용하여 서버를 끄면 데이터가 불안정했습니다. | 안정적인 오라클(Oracle 19c) 데이터베이스로 바꾸었습니다. 테이블 생성과 기본 데이터 입력 스크립트(schema_oracle.sql)도 함께 제공합니다. |
| 화면 디자인 | 옛날 기본 스타일이라 글씨가 작고 네모 상자 위주의 투박한 모양이었습니다. | 어두운 톤의 최신 게이밍 느낌으로 새단장했습니다. 글씨체를 보기 편한 폰트로 바꾸고, '파티 모집'과 '자유'를 한눈에 알아볼 수 있도록 색상 태그를 달았으며, 화면 크기에 맞게 자동으로 정돈되도록 손보았습니다. |
| 비밀번호 찾기 메일 | 메일 보내는 서버 설정이 비어 있어서 실제로 비밀번호 찾기 메일이 보내지지 않았습니다. | 메일 설정 파일(smtp.properties)을 연결하고 필수 라이브러리를 추가하여, 실제로 메일이 정상적으로 발송되도록 고쳤습니다. |
| 개발자 정보 | 다른 팀원 이름과 사용하지 않는 이메일이 남아 있었습니다. | 모든 화면과 코드에서 다른 인물 정보를 지우고, 박성국 1인 개발자 정보로 통일했습니다. |
| 개발 도구 오류 해결 | 서블릿 기본 라이브러리가 빌드 경로에 없어서 개발 도구(이클립스)에서 오류 표시가 떴습니다. | 설정 파일(pom.xml)에 서블릿과 JSP 라이브러리를 추가하여 개발 도구에서 경고나 오류 없이 열리도록 해결했습니다. |
